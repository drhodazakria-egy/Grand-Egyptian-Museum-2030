# Grand Egyptian Museum 2030 (المتحف المصري الكبير 2030)

مستودع مشروع **المتحف المصري الكبير 2030**، يضم ملفات ومخرجات فرق العمل والنسخة النهائية من المشروع:

- **Final Project (المشروع النهائي)**: المخرجات النهائية، بطاقات الشخصيات (Character Sheets)، والملخصات والتقارير المعتمدة.
- **Hoda (هدى)**: مساهمات وفيديوهات وتقارير العمل الخاصة بـ Hoda.
- **Kholoud (خلود)**: ملفات العرض، الصور، والمواد التوثيقية الخاصة بـ Kholoud.
- **Mariam (مريم)**: عروض تقديمية (Presentations)، مستندات الإنتاج، والمقاطع الخاصة بـ Mariam.
- **Mohamed Wafy (محمد وافي)**: مستندات وتقارير وملفات العمل الخاصة بـ Mohamed Wafy.
